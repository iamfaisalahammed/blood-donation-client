## 📌 Project Overview

Blood Donation Application is a full-stack platform designed to connect blood donors and recipients easily. It provides a simple system for managing donors, blood requests, users, donations, and website content.

## 🛠️ Technologies

Built with **React, Vite, Tailwind CSS, DaisyUI, Firebase, React Router, React Hook Form, TanStack Query, Node.js, Express.js, MongoDB, JWT, Stripe, Nodemailer, Jodit React, SweetAlert2, and React Toastify.**

## Key Features

* Role-based authentication for Admin, Donor, and Volunteer
* Create, manage, approve, and reject blood donation requests
* Search and filter donors by blood group and location
* Admin dashboard for managing users, requests, and content
* Blog management with rich text editing
* Email notifications for important activities
* Stripe integration for supporting donations
* Donation request status management
* Fully responsive design for mobile, tablet, and desktop
